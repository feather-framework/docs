# OpenAPI
---

Feather OpenAPI helps you describe HTTP API contracts using Swift.

OpenAPI documents define the shape of your API: endpoints, parameters, request bodies, responses, schemas, tags, and security requirements. Once the document exists, it can be used for documentation, server generation, client generation, and contract testing.

In a Feather Framework project, OpenAPI is the bridge between the public API contract and the Swift implementation. The server can register generated handlers with Hummingbird or Vapor, while other Swift applications can use a generated type-safe client.

Start with the overview, then read the document, server integration, and client integration guides.
