# HTTP
---

Feather HTTP provides shared request and response building blocks for Swift backend applications.

It helps with three common jobs: making real outgoing HTTP requests, testing routes through the same request model, and connecting a Feather or FATHOMS-style application to an HTTP server.

Feather does not replace Hummingbird or Vapor. Those frameworks handle the HTTP server layer. Feather HTTP gives your application a consistent way to describe requests, execute them, inspect responses, and test behavior across server implementations.

Start with the overview, then continue with clients, testing, and server setup.
