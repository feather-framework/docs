# FATHOMS
---

FATHOMS means **Feather Architecture for Highly Organized Modular Systems**.

It is the application architecture used with Feather to keep larger server-side Swift projects understandable. FATHOMS organizes code into modules, layers, use cases, scopes, adapters, and server assembly boundaries.

The goal is not to add ceremony. The goal is to make it clear where business rules belong, where infrastructure belongs, how modules communicate, and how a project can grow without turning into one large mixed folder.

Start with the overview for the main ideas, then continue with modules, the server layer, and RBAC.
